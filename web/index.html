Poverty Mapping Pipeline

This page is served from your local Python HTTP server and reflects the current state of the automation pipeline.

Demo Workflow Artifacts

  • Synthetic features: demo_data/synthetic_features.tif
  • Synthetic poverty map: demo_data/synthetic_poverty_map.tif

To (re)generate these demo layers, run in a terminal: 

python scripts/demo_full_workflow.py

You can then configure your JavaScript web map (e.g. Leaflet, MapLibre, deck.gl) to load demo_data/synthetic_poverty_map.tif from this same origin.

GEE Extraction Pipeline

The backend Python package exposes a quarterly GEE pipeline. From the project root:

python -m src.workflow.run_pipeline --year 2023 --quarter 3 --datasets sentinel2 landsat modis chirps dem

Monitor tasks in the Google Earth Engine Tasks console, then download exports and feed them into your preprocessing + model stack.

Tests & CI

To run tests with coverage locally:

pytest

GitHub Actions CI is configured in .github/workflows/ci.yml to run the same suite.
